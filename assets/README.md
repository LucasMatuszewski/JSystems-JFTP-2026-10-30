# JSystems reference and desktop assets

`logo.svg`, `homepage.png` and the design tokens are the supplied website reference.
Keep those original files intact when comparing desktop changes with the brand.

`logo-desktop.svg` is the English desktop variant. It removes only the small
outlined Polish caption below the wordmark. The remaining 14 paths, their order,
colors and geometry are identical to the original. Its `230 × 72` view box is
unchanged, so the full mark and wordmark retain their proportions and clear space.
No replacement slogan, font or remote asset is introduced.

The variant was inspected beside the original in a real SVG browser renderer.
The [comparison](../docs/testing/evidence/logo-variant/comparison.png) and
[receipt](../docs/testing/evidence/logo-variant/receipt.json) record that check.
Native inspection of the packaged header remains part of desktop acceptance.
