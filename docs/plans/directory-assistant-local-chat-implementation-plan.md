## 1. Demonstrable outcome and authority

Deliver one complete local-directory flow inside the existing branded Swing application: attach its displayed local listing, inspect the snapshot, enter a temporary key, accept the disclosure, ask a question, receive a real completed OpenRouter answer, and ask a follow-up. Demonstrate unchanged snapshot context after navigation, a recoverable failure/manual retry, reset, tab isolation and clearing state on exit. Existing manual FTP/FTPS behavior remains available.

This is a staged subset of the [approved assistant scope][P-flow], not completion of the whole feature. Expose local attachment only in this slice and identify it as local-directory analysis. Remote-directory attachment and its readiness changes are deferred; do not claim AC-08 or TAC-006-03 passed. File-content analysis, AI transfers, AG-UI, streaming, platform migration and a new application scaffold remain outside this slice. The remote pane itself must continue working normally.

The sources of truth are the [PRD criteria][P-ac], [ADR-006 module contracts][A-modules] and [interfaces][A-contracts], and [ADR-007 provider contract][B-contracts] and [limits][B-limits]. Use the approved [desktop requirements][Brand] and design guidance for [colors][D-colors], [controls][D-controls] and [logo][D-logo], with [the supplied screenshot](../../assets/homepage.png). Preserve the existing Swing theme/font choices; website extraction examples do not require downloading fonts or replacing desktop components. Course exercises and named-role examples are not product requirements.

Architecture already chooses the provider, model, temporary state, request limits and threading boundary. This plan does not redefine them. If the SDK serialization/deadline probe or implementation exposes a consequential missing contract, the orchestrator must propose an amendment to ADR-006/007 and obtain a decision before delegating dependent code. A worker cannot resolve it through a new dependency, different endpoint or invented assumption.

## 6. Failure handling, fallback and review gate

**Readiness gaps, not new architecture decisions:** deliberately supplied live test credentials, usable native desktop/human QA, SDK artifact/hook compatibility and eventual remote publication permissions have not been established. T0 records them before dependent work. No secret scanning or billable request is authorized merely by this planning task. Missing safe service captures block endpoint fixture creation under [ADR-007][B-gate]; deterministic application-owned gateway fakes must not pretend to be captured provider responses.

On a failed assertion, first inspect production behavior and fixtures; do not weaken tests or redefine the PRD. A failed dependent check reopens its owner row and invalidates downstream acceptance as appropriate. A shared-contract change requires orchestrator review and fresh briefs. If provider behavior conflicts with the approved contract, stop and propose an ADR amendment rather than introducing direct HTTP, Chat Completions or a Java upgrade as a hidden fallback.

Before a commit, discard only explicitly owned uncommitted edits after reviewing their diff; never reset unrelated work. After a verified feature commit, rollback is a focused revert on the feature branch followed by the relevant build/runtime checks, not a force push or hard reset of master. Cancelling local work cannot revoke an already submitted provider call or promise a refund. Fixture cleanup must stop only owned processes and remove only verified paths under the synthetic run root.

If time/tool/model access runs out, prefer sequential execution by the primary agent with the same briefs and gates. The smaller demonstrable fallback is a local snapshot inspector in the existing Swing workspace with no provider call; it is a separately reviewed partial milestone, **not** successful delivery of directory Q&A. Do not substitute a canned model answer. If native or service access remains absent, hand off the reviewed diff/evidence and mark the corresponding flow unverified rather than publish a finished-slice claim.
